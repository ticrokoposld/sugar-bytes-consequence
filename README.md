## Overview

Sugar Bytes Consequence is a generative MIDI sequencer that applies probability rules, note transforms, and conditional logic to create self-evolving melodic and rhythmic patterns.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sugar Bytes Consequence** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Rule Engine** | Conditional rules transform notes based on pitch, velocity, and position |
| **Probability** | Per-step probability controls whether each note triggers |
| **Transformations** | Transpose, invert, reverse, and arpeggiate sequences in real time |
| **MIDI Output** | Routes generated MIDI to any DAW instrument for maximum flexibility |
